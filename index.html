Reproducible pipeline

Method, provenance & limitations

What was measured, joined, transformed and intentionally left blank.

01

Repair coordinates

The source web routes declare CRS84 but contain UTM Zone 36N coordinates. Coordinates are reinterpreted as EPSG:32636, forced to 2D and transformed to EPSG:4326.

02

Assign stable IDs

Each link receives a deterministic ID from district, source code, road name and geometry. Re-running unchanged source data yields the same ID.

03

Split by boundaries

Every line is intersected with the official parish layer. Covered lengths are calculated in metres and rolled up to parish, subcounty, county and district.

04

Join without invention

AADT, PCU and speed are populated only on exact source-code matches to the supplied DUCAR link registry. Missing traffic stays null and is reported as a coverage gap.
